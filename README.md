### 3. Проект: Реализация Дерева Решений и Случайного Леса с нуля 🌲

В данном проекте представлена собственная объектно-ориентированная реализация базовых алгоритмов машинного обучения для задачи классификации: **Дерева Решений (Decision Tree)** и ансамблевого метода **Случайного Леса (Random Forest)** на чистом Python с использованием библиотек `NumPy` и `Pandas`.
* **Ссылка на дерево решений:** [Myself_DecisionTree.ipynb](./Myself_DecisionTree.ipynb)
* **Ссылка на случайный лес:** [Myself_RandomForest.ipynb](./Myself_RandomForest.ipynb)
  
🛠 3.1. Архитектура и компоненты решения
Разработанные классы:
1. **`Node`** — класс-контейнер, представляющий собой узел или лист графа дерева. Хранит ссылки на дочерние элементы (`left`, `right`), параметры разделения выборки (`feature`, `threshold`) или предсказанный класс/вероятность (если узел является листом).
2. **`Decision_tree`** — базовая модель одиночного дерева решений. Поддерживает рекурсивное построение структуры от корня к листьям.
3. **`Random_Forest`** — ансамблевая модель, объединяющая несколько одиночных деревьев в одну систему для снижения дисперсии и повышения точности предсказаний.

3.2. Ключевые особенности реализации
* **Критерии информативности:** В одиночном дереве реализована поддержка двух классических функций потерь для оценки качества сплита:
  * **Индекс Джини (`gini`)** — измеряет степень неопределенности распределения классов в узле.
  * **Энтропия Шеннона (`entropy`)** — оценивает хаотичность данных с использованием логарифма по основанию 2.
* **Механизмы регуляризации:** Для предотвращения переобучения дерева интегрированы параметры остановки рекурсии: `max_depth` (максимальная глубина) и `min_samples_split` (минимальное число объектов для сплита).
* **Инструменты отладки и визуализации:** 
  * Параметр `log=True` активирует пошаговое текстовое логирование процесса рекурсивного построения с визуальными отступами глубины.
  * Метод `print_tree` строит наглядный граф обученного дерева прямо в консоли.
* **Оптимизация скорости:** В методе `predict` используется предварительная конвертация тестового датафрейма в легковесный список словарей (`to_dict(orient='records')`), что значительно ускоряет итеративный обход дерева по сравнению со стандартным методом `.iterrows()`.

3.3. Принцип работы Случайного Леса (Bagging)
Обучение ансамбля строится на концепции **Бэггинга (Bootstrap Aggregating)**:
1. Для каждого из `n_estimators` деревьев формируется случайная подвыборка (бутстрап-выборка) строк из исходного датасета с возвращением (`replace=True`). Это обеспечивает уникальность обучающего набора для каждого дерева.
2. Каждое дерево обучается независимо на своем подмножестве данных.
3. **Логика работы `predict`:** При предсказании модель собирает ответы всех деревьев для каждого объекта через срез матрицы ответов (`all_tree_preds[:, i]`) и выносит финальный вердикт на основе **мажоритарного голосования** (класса большинства), используя инструмент `collections.Counter`.


### 4. Проект: Логистическая Регрессия и Многоклассовая Классификация (One-vs-Rest) с нуля 🔬

Собственная объектно-ориентированная реализация алгоритма классификации на чистом Python и NumPy без использования готовых моделей из scikit-learn.

* **Ссылка на проект:** [Myself_logisticRegression.ipynb](./Myself_logisticRegression.ipynb)
* **Цель:** Изучение математики линейной классификации, градиентного спуска и механизмов регуляризации.

#### 🛠 Ключевые особенности реализации
* **Численная стабильность:** Сигмоида защищена от переполнения памяти (`overflow`), а функция потерь LogLoss застрахована от логарифма нуля через `np.clip`.
* **Регуляризация ElasticNet:** В градиентный спуск интегрированы штрафы **L1 (Lasso)** на основе `np.sign` для отбора признаков и **L2 (Ridge)** для предотвращения переобучения.
* **Ранняя остановка (Early Stopping):** Цикл оптимизации досрочно прерывается, если изменение ошибки между эпохами становится меньше заданного порога `stop_gr`.
* **Многоклассовый интерфейс (One-vs-Rest):** Класс-обертка `MCLogisticRegression` позволяет решать задачи с 3+ классами (проверено на датасете *Iris*). Финальный класс выбирается по максимальной вероятности через `np.argmax`.
* **Аналитика:** Метод `predict_proba_df` возвращает структурированную таблицу Pandas с вероятностями, а свойство `plot_loss` визуализирует график обучения.

* **Стек технологий:** Python, NumPy, Pandas, Matplotlib, Scikit-learn (только для загрузки данных и масштабирования).
