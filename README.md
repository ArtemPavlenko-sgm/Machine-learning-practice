## 📁 Портфолио проектов

### 1. Линейная регрессия с нуля 🧪
* **Ссылка на проект:** [`linear_regression_from_scratch.ipynb`](./linear_regression_from_scratch.ipynb)
* **Цель проекта:** Углубить понимание математических основ линейных моделей путем аналитической реализации регрессии методом наименьших квадратов (МНК) и её прямого сравнения с `scikit-learn`.
* **Ключевые этапы реализации:**
  * Добавлен вектор смещения (столбец единиц) в матрицу признаков.
  * Реализована формула нормального уравнения: $w = (X^T X)^{-1} X^T y$.
  * Создана логика предсказания на основе рассчитанных аналитических весов.
  * Алгоритм градиентного спуска на базовом питоне.
* **Стек технологий:** Python, Jupyter Notebook, NumPy, Pandas, Scikit-learn.

### 2. Кластеризация K-Means с ООП и кастомными метриками 📊

* **Ссылка на проект:** [KMeans with OOP.ipynb](KMeans%20with%20OOP.ipynb)
* **Цель проекта:** Реализация полноценного класса `Kmeans` на чистом Python и NumPy для группировки данных без учителя. Проект демонстрирует объектно-ориентированный подход (ООП) в разработке ML-алгоритмов с нуля.
* **Основные фичи:**
  * Поддержка трех метрик расстояния: Евклидово (`Euclid`), Манхэттенское (`Manhattan`) и Чебышёва (`Max`).
  * Наглядное исследование фундаментальных ограничений K-Means на сложных геометрических структурах данных (вложенные кольца).
* **Стек технологий:** Python, NumPy, Pandas, Scikit-learn (генерация данных), Seaborn / Matplotlib (визуализация).
